# Projekt einrichten

## Voraussetzungen

- Git
- Webbrowser
- Texteditor

## Installation

1. Klone das Repository:

   ```bash
   git clone https://github.com/Rayan-meier/Projekt-Dokumentation.git
   ```

2. Öffne den Projektordner.
3. Bearbeite die Markdown-Dateien mit einem Texteditor.
4. Lade die Änderungen auf GitHub hoch.
